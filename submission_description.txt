This Week 4 project demonstrates a complete machine-learning model development and evaluation workflow using Python and scikit-learn. The objective is to train, validate, compare, and critically evaluate two supervised classification algorithms on a publicly available dataset.

The project uses the Wisconsin Diagnostic Breast Cancer dataset bundled with scikit-learn. It contains 569 records and 30 numeric features describing characteristics of cell nuclei. For clearer evaluation, the target is configured so that malignant cases are the positive class and benign cases are the negative class. This is an educational exercise only and is not intended for clinical diagnosis or medical decision-making.

The workflow separates features and labels, then creates a stratified 75/25 training and test split with a fixed random seed. Median imputation is included in the model pipelines to support robust preprocessing. Logistic Regression uses feature standardization, while a Decision Tree is constrained by maximum depth and minimum leaf size to reduce the risk of overfitting. Both models are evaluated on the same held-out test set.

The report compares accuracy, precision, recall, F1-score, and ROC-AUC. It includes a model-performance comparison chart, a confusion matrix, and ROC curves. Five-fold cross-validation is performed on the training data to provide an additional view of model stability. The analysis also discusses false positives, false negatives, class imbalance considerations, overfitting, data leakage, dataset limitations, threshold selection, and the need for independent external validation.

The final DOCX report explains the dataset, preprocessing, algorithm selection, methodology, metrics, results, visualizations, limitations, and possible improvements. The accompanying Python script reproduces the experiment and saves the evaluation charts. The project emphasizes that model quality should be judged using multiple metrics and careful error analysis rather than accuracy alone.
